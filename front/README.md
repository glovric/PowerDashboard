# front

This is the frontend component of the PowerDashboard.

## Local setup

⚠️ **Important**  ⚠️

Before the frontend is run locally configure dev server proxy in `vue.config.js`. The `target` attributes need to contain valid URLs for each service.

### Requirements

- **[Node.js + npm](https://nodejs.org/)** or 
- **[bun](https://bun.sh/)**

### Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

### Clear cache
```
npm cache clean --force
```
